# Lyphe

This app is meant to be a life dashboard combined with a powerful agent. This tracks long term goals, tasks to meet those goals, habits, and a full personal journal that can be tied to anything within the app. This can be tied to any existing agent with an MCP link.

## Features

- Life Goals
- Tasks to get to those goals
  - Goals are optional, you can simply have things to do!
- Daily, weekly, and monthly habits
  - Web based reminders for habits with set times and cadence
- Journal entries with related tasks, goals, and habits
  - Copilot style autocomplete with a local model via llamafile
  - Local transcription support via transcribefile
