# Lyphe frontend

React Router SPA with Plate, shadcn, and PocketBase authentication. Run `bun install`, then `bun run dev`. The default development API is http://127.0.0.1:8090; set `VITE_PB_URL` to override it.

Use `bun run test`, `bun run typecheck`, and `bun run build` to check changes. Production assets are in `build/client` and are served by the Go application. The parent README describes the backend, local model processes, storage, and API.
